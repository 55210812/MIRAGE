### 1.1 这次样本是什么

问题：

```text
Why is it bad to eat cookie dough for risk of salmonella but things like Cookie Dough Bites are ok?
```

使用的检索文档标题：

1. How to Treat and Prevent Food Poisoning - MsPrepper
2. FDA Issues Warning About Eating Raw Cookie Dough, But Not For Salmonella Risks

### 1.2 原始生成答案

这是 `run.py` 直接生成的答案，还没有经过 MIRAGE citation 重写：

```text
 The risk of salmonella from eating raw cookie dough is primarily due to the presence of raw eggs, which can harbor the bacteria. However, the FDA has recently warned against consuming raw dough for another reason: the potential contamination of raw flour with harmful bacteria, such as E. coli and Salmonella. [1][2
```

观察点：

- 答案已经在讨论 raw eggs、raw flour、FDA warning 等内容。
- 原始输出末尾出现了不完整 citation 片段 `[1][2`。
- 这说明如果只依赖模型自己生成 citation，格式和可信度都不稳定。

### 1.3 MIRAGE 加引用后的答案

这是 `mirage_cite.py` 根据模型内部 attribution 重新写 citation 后的答案：

```text
 The risk of salmonella from eating raw cookie dough is primarily due to the presence of raw eggs, which can harbor the bacteria. [1] However, the FDA has recently warned against consuming raw dough for another reason: the potential contamination of raw flour with harmful bacteria, such as E. coli and Salmonella.
```

观察点：

- 第一句被加上 `[1]`。
- 第二句没有 citation。
- 这里的 citation 不是模型自己自由生成的，而是 MIRAGE 根据 token attribution 计算出来的。

### 1.4 评估分数怎么看

| 指标 | 当前值 | 怎么理解 |
| --- | ---: | --- |
| `length` | 51.0 | 答案平均词数。smoke 只有 1 条样本，所以就是这条答案长度。 |
| `str_em` | 0 | 短答案 exact match 指标；当前 ELI5 smoke 不是这个指标的主要场景。 |
| `str_hit` | 0 | 短答案 hit 指标；当前 ELI5 smoke 不是这个指标的主要场景。 |
| `rougeLsum` | 18.666666666666668 | 生成答案与参考答案的 ROUGE-Lsum 内容相似度。smoke 只用于链路验证，不代表完整论文性能。 |
| `citation_regex_sentences` | 2 | 加 citation 后答案被切成的句子数。 |
| `citation_regex_cited_sentences` | 1 | 带有 citation 的句子数。 |
| `citation_regex_valid_sentences` | 1 | citation 编号在文档范围内的句子数。 |
| `citation_regex_rec` | 50.0 | 句子级 citation 覆盖率。 |
| `citation_regex_valid_rate` | 50.0 | 句子级合法 citation 覆盖率。 |
| `citation_regex_avg_citations` | 0.5 | 平均每句 citation 数。 |

汇报时不要把这个 `.score` 说成完整论文指标。本次是 smoke，目标是证明链路跑通：

```text
生成答案 -> 内部归因 -> 自动加 citation -> 轻量评估
```

其中 citation 评估使用的是 `--citation_regex_only`，只检查 citation 是否存在、编号是否合法，不判断语义上是否完全支持。完整论文评估需要 AutoAIS / NLI 模型，成本更高。

## 2. 代码怎么看

建议按链路看，不要从所有文件随机翻。

### 2.1 第一层：运行入口

先看：

```text
scripts/run_smoke_deepseek.sh
```

它做 6 件事：

1. 找 Python 环境。
2. 加载 `.env`。
3. 检查 `torch`、`transformers`、`inseq` 和 CUDA。
4. 检查 DeepSeek 本地 HF 模型目录。
5. 依次运行 `run.py`、`mirage_attribute.py`、`mirage_cite.py`、`eval.py`。
6. 检查每一步输出文件存在。

### 2.2 第二层：实验配置

再看：

```text
sec5_longQA/configs/eli5_deepseek_qwen14b_shot0_ndoc2_bm25_selfcitation_smoke.yaml
```

它控制本次 smoke 的核心参数：

- 使用 DeepSeek 本地模型：`/home/intern/models/DeepSeek-R1-Distill-Qwen-14B`。
- 使用 1 条 ELI5 smoke 数据。
- 每条问题使用 2 篇检索文档。
- 最多生成 64 个 token。
- 禁用采样，保证 smoke 更稳定。

### 2.3 第三层：生成答案

看：

```text
sec5_longQA/run.py
```

主逻辑：

1. 读取 YAML 配置。
2. 读取 prompt 模板和 eval 数据。
3. 用 `utils.make_demo()` 拼 RAG prompt。
4. 用 `utils.load_model()` 加载 DeepSeek HF 模型。
5. 调用 `model.generate()` 生成答案。
6. 保存到 `result/selfcitation/*.json`。

本次适配点：

- 增加 DeepSeek/Qwen 的 stop token 和 max length 处理。
- 增加 `do_sample` 参数，smoke 配置中设为 `false`。

### 2.4 第四层：MIRAGE 核心归因

看：

```text
sec5_longQA/mirage_attribute.py
```

主逻辑：

1. 读取 `run.py` 的生成结果。
2. 重新加载同一个 DeepSeek HF 模型。
3. 用 `inseq.load_model(..., "saliency")` 包装模型。
4. 构造带上下文输入和无上下文输入。
5. 用 `contrast_prob_diff` 计算上下文对答案 token 的影响。
6. 写出 `internal_selfcitation/*.json`。

这是 MIRAGE 和普通 RAG 的最大区别：它不是让模型自己解释引用，而是直接看模型内部 attribution。

### 2.5 第五层：把归因转成 citation

看：

```text
sec5_longQA/mirage_cite.py
```

主逻辑：

1. 读取生成答案 JSON。
2. 读取对应的内部归因 JSON。
3. 把答案切成句子。
4. 通过 CTI 选择上下文敏感的答案 token。
5. 通过 CCI 选择贡献最大的上下文 token。
6. 按文档分隔符把 token 贡献聚合到文档级别。
7. 给句子加 `[1]`、`[2]` citation。

本次参数：

```bash
--CTI 1 --CCI -5
```

含义：

- `CTI 1`：只关注高于平均值 1 个标准差以上的上下文敏感 token。
- `CCI -5`：保留贡献分数 top 5% 区域。

### 2.6 第六层：评估

看：

```text
sec5_longQA/eval.py
```

本次 smoke 使用：

```bash
eval.py --citations --citation_regex_only
```

它会计算：

- 答案长度。
- ROUGE-Lsum。
- citation 是否存在。
- citation 编号是否在文档范围内。

注意：`--citation_regex_only` 不做语义支持判断；完整 citation 语义评估需要 AutoAIS。
